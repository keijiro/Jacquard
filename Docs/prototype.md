# Jacquard Project

## プロジェクトの目的

このプロジェクトでは、少し変わったシーケンサを持つ音楽アプリ "Jacquard" を Unity で作成します。

## コンセプト

このアプリはプロシージャルで自由度の高いシーケンサを持つ音楽アプリです。次のような先行する製品をインスピレーションの源泉としています。

- いわゆる Tracker, https://en.wikipedia.org/wiki/Music_tracker
- 100R Orca, https://100r.co/site/orca.html
- Fors FMS, https://lo-bit.club/fms
- Elektron ハードウェアシンセ

ユーザーは平面上にタイルを配置することでシーケンスを構築します。これは初心者にとっては単に１６個のスロットにノートを並べるだけのシンプルなステップシーケンサに見えますが、複数のタイルを縦にスタックしたり、特殊な機能を持つタイルを活用することで、複雑なシーケンスが組めるようになります。

ユーザーは単一の横軸（レーン）だけではく、複数のレーンを平面上に展開することができます。また、それらのレーンの間をジャンプしたり、分岐したりもできます。そのような複数レーンの組み合わせが、シーケンスに複雑な変化をもたらします。

このシーケンサの仕様については、sequencer.md に詳しくまとめてあります。また、そのモックアップが mockup.html に構築されています。

## 使用する Unity スタック

Unity 6.5 を使用します。Unity CLI と Pipeline パッケージを活用し、エージェントが自動制御を行える体制を整えます。

画面上の描画は UI Toolkit を使用します。ユーザーの入力にはいわゆる new input system を使用します。Render Pipeline は URP を使用しますが。今回のプロトタイプにおいては URP 経由での描画要素は殆ど無い（あるいは全く無い）かもしれません。

## 音源部

音源は比較的シンプルな２オペレーター FM 音源を使用します。これについては別途プロトタイピング行っているので、それを流用します。

https://github.com/keijiro/unity-sap-test

Unity の Scriptable Audio Pipeline の使用方法についても、このプロジェクトが参考になります。

## ビジュアルスタイル

フラットかつモノクロでシンプルなスタイルを全体的に適用します。 mockup.html に構築済みのモックアップがベースとなります。

## 不足している情報

次のような要素の情報が明らかに不足していますが、これはエージェント側で任意に設計・実装を行うことを期待されています。

- ファイルセーブ・ロード等の基本的なアプリケーションレベルの UI
- シーケンスを編集する UI
- プレイ開始・停止などの基本制御 UI

## 実装に当たって意識すべき点

実装に当たっては、UnityEngine 依存部分と、UnityEngine 非依存部分をなるべく分離し、オブジェクトの管理やシリアライズ処理において UnityEngine 由来の機能を使用しないことを意識します。

次のようなイメージで考えています。ただしこれはざっと考えたうえでの構想であり、もしこのような状態の維持が難しい、あるいは技術的に明らかに不利であると考えられるようであれば、これを変更しても構いません。

#### UnityEngine 非依存、かつ相互に独立し得るモジュール群

- FM 音源の波形生成処理
- シーケンスデータ表現
- シーケンスデータのシリアライズ・デシリアライズ処理
- シーケンサ実行処理

#### UnityEngine 依存、かつ相互依存の切り離しが難しいモジュール群

- Scriptable Audio Pipeline への波形供給処理
- シーケンサと音源の繋ぎ込み
- シーケンスデータのファイル保存・読み込み処理
- シーケンサ UI
